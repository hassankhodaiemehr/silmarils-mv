# silmarils-code

Research code for **SILMARILS** ([arXiv:2605.03230](https://arxiv.org/abs/2605.03230)), an information-theoretic and quantum-secure designated-verifier signature framework, and **SILMARILS-MV**, a multi-validator extension with threshold notarization and HotStuff-scale evaluation (IEEE TIFS submission; preprint forthcoming).

## Layout

| Path | Contents |
|------|----------|
| [`silmarils-mv/`](silmarils-mv/) | SILMARILS-MV reference implementation: C/Python models, `hsbench/` HotStuff prototype, and reproduced benchmark results. See [`silmarils-mv/README.md`](silmarils-mv/README.md). |
| [`silmarils/simulation/`](silmarils/simulation/) | Original SILMARILS simulation scripts and paper figures. See [`silmarils/simulation/README.md`](silmarils/simulation/README.md). |
| [`silmarils/demo/`](silmarils/demo/) | Interactive demo and API for exploring SILMARILS behavior. See [`silmarils/demo/README.md`](silmarils/demo/README.md). |
